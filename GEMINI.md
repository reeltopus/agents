# Reeltopus

Reeltopus turns long videos into short vertical clips with captions and posts them. Use its tools to check
hours (get_account), find the user's videos (list_projects), wait for processing (get_status), read the ranked
clips (get_clips), edit and export them (edit_clip, export_clip, get_export) and schedule posts (schedule_post).
Confirm with the user before posting anything publicly. Sign in when asked: Reeltopus uses OAuth.
